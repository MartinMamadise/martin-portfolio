Current Research

BEng Tech Honours Project

Location-Dependent Network Quality Measurement & Prediction for Wireless Networks

Ongoing · the most detailed and technically layered project in this portfolio, integrating Linux systems, network measurement, spatial data and machine learning into one reproducible pipeline.

Ubuntu/LinuxPythonBashiperf3Wireshark/tcpdumpPostgreSQL/PostGISScikit-learnDash/PlotlyQGIS

Wi-Fi quality varies by location and time due to distance from access points, obstacles, interference and congestion. This system links network-quality measurements to GPS coordinates so performance can be analysed spatially, and eventually predicted at locations without direct measurements. The architecture is organised into six phases:

1
GPS + Wi-Fi
Location & RSSI
2
Measurements
ping / iperf3
3
Automation
Python + Bash
4
Storage
PostgreSQL + PostGIS
5
Analysis / ML
Pandas + RF/XGBoost
6
Visualisation
Dash/Plotly + QGIS
Parameter What it represents Measurement approach
RSSI Received signal power; indicator of wireless coverage/signal quality iw / iwconfig · dBm
Latency Delay during packet transmission; lower is more responsive ping / ICMP · ms
Throughput Data successfully transferred over a period of time iperf3 · Mbps
Packet Loss Percentage of packets failing to reach the destination ping / iperf3 · %
Completed / in progress

Architecture and measurement methodology are defined. The data-collection phase has started, with current work focused on collecting wireless measurements at the first measurement location.

Designed / specified

Automated Python + Bash measurement loop, GPS timestamping via gpsd/gps3, RSSI/latency/throughput/packet-loss collection, cron scheduling, error logging and PostgreSQL/PostGIS storage.

Planned next

Feature engineering with Pandas/NumPy; Random Forest & XGBoost regression evaluated with RMSE, MAE and R²; Dash/Plotly dashboard; QGIS mapping.

Scope

Wi-Fi / IEEE 802.11 in campus environments. Cellular 4G/5G is outside the current scope.

Traffic Engineering via Graph Theory & Linear Programming

PythonNetworkingGraph TheoryLinear ProgrammingOptimization
GitHub ↗

Network optimization system built around the NSFNET backbone topology that models traffic flow using graph theory and linear programming. Compares shortest-path routing (Dijkstra's) against Single-Commodity and Multi-Commodity Flow optimization to demonstrate real-world routing limitations at scale.

Stack NetworkX, PuLP + CBC Solver, Pandas, Matplotlib
Methods Dijkstra baseline → SCF cost minimization → MCF with Min-Max Utilization
MCF reduced maximum link utilization from over 600% down to under 75% — demonstrating traffic engineering strategies used in modern backbone networks.
